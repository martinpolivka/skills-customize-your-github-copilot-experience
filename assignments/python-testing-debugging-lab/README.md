# 📘 Assignment: Python Testing and Debugging Lab

## 🎯 Objective

Learn how to write and run unit tests with Python's built-in `unittest` module, then debug and improve a small codebase so it passes all required tests.

## 📝 Tasks

### 🛠️	Write Unit Tests for Core Functions

#### Description
Use `unittest` to test core behavior in the provided starter code. Focus on realistic cases, including edge cases that often cause bugs.

#### Requirements
Completed program should:

- Create tests in `test_starter.py` for `calculate_average`, `is_strong_password`, and `format_username`
- Include at least 2 edge-case tests (for example: empty lists, short passwords, extra spaces)
- Use clear test method names and meaningful assertions


### 🛠️	Debug and Refactor the Starter Code

#### Description
Run your tests, identify failures, and fix the implementation in `starter-code.py` so behavior matches the expected rules.

#### Requirements
Completed program should:

- Fix all bugs so all tests pass with `python3 -m unittest test_starter.py`
- Keep function names and function signatures unchanged
- Add concise comments explaining at least 2 non-obvious fixes
